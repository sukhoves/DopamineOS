# Контроль времени в браузере

Проект для контроля времени, проводимого на развлекательных сайтах. Состоит из приложения для macOS и расширения для Safari.

## 📦 Состав проекта

### 1. Приложение для macOS
- Работает в фоновом режиме
- Проверяет активность расширения Safari
- При отключении расширения блокирует весь экран (клавиатура, мышь, тачпад, сочетания клавиш)
- Разблокировка доступна только на 10 секунд для включения расширения

### 2. Расширение для Safari
- Устанавливает лимиты времени на посещение определенных URL
- Блокирует доступ к заданным паттернам

## 🛠 Как работает

### 🔄 Мониторинг расширения
Приложение постоянно проверяет активность расширения. При его отключении активируется полная блокировка системы.

### ⏱️ Контроль времени по категориям
Расширение работает с 4 категориями (настраивается в исходном коде):
1. **Музыкальные сервисы**
2. **Социальные сети и новости**
3. **Кино и сериалы**
4. **Видеохостинги**

Для каждой категории устанавливается индивидуальный лимит времени. При переходе на сайт, соответствующий паттерну категории, запускается таймер. По истечении лимита доступ к сайту блокируется до следующего дня.

### 🚫 Блокировка по ключевым словам
Отдельный модуль блокирует переходы по ссылкам, содержащим ключевые слова из настраиваемого списка:

- **При вводе ключевого слова в поисковую строку** — результат выдачи заменяется на блокирующий экран
- **При клике на ссылку с ключевым словом** — браузер не перенаправляет пользователя, показывает всплывающее уведомление

## 🎯 Сценарий использования

Проект подходит тем, кто хочет контролировать время, проводимое на развлекательных сайтах.

### Преимущества перед macOS «Экранное время»:
- **Гибкая настройка лимитов** по категориям сайтов
- **Точечный контроль** — можно отделить личное общение (например, Telegram чаты) от развлекательного контента (Telegram каналы)
- **Блокировка по ключевым словам** для дополнительного контроля
